# Emberwake: Last Lantern

A top-down arena survival game for make.fun's best-game-01. You are the last lantern spirit: move with WASD, aim with the mouse, hold click to fire, Space to dash. Clear 6 waves (the last is the Gloomhorn boss), picking one of three gifts between waves.

Run it: `node serve.ts`, then open http://localhost:8080. Build the entry: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
